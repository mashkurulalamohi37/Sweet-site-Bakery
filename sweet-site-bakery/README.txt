SWEET SITE BAKERY - WEBSITE
===========================

WHAT'S INSIDE
  index.html       The complete website (one file, logo already built in)
  assets/logo.jpg  Your original logo, for reference or printing

OPEN IT ON YOUR COMPUTER
  Double-click index.html. It opens in your web browser.

PUT IT ONLINE (free options)
  - Netlify Drop: go to app.netlify.com/drop and drag this folder onto the page.
  - GitHub Pages: upload index.html to a GitHub repository and turn on Pages.
  - Any web hosting (cPanel etc.): upload index.html to the public_html folder.

HOW ORDERS WORK
  Customers add cakes to the cart and tap "Send order on WhatsApp".
  The order arrives on WhatsApp at 01852-668468 as a ready-written message.

CHANGING THINGS
  Prices and products are in index.html, in the section marked
  "Catalog (SPEC 6 - exact names and prices)". Edit with any text editor.
